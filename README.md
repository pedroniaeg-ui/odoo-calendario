# Odoo Calendario

Collegamento tra Google Calendar e il calendario Odoo di Pedroni Angelo e Giuseppe snc.

L’applicazione permette di sincronizzare gli appuntamenti di lavoro tra i due sistemi, dopo l’autorizzazione dell’account Google interessato.

Il collegamento è destinato all’organizzazione delle attività aziendali.
